# 迭代一 · 复用构件设计说明（UI 侧接入口）

> 对应 D6“复用设计”任务；成员1 已实现构件，成员3 只负责在 UI 侧接入，不重复造轮子。

## 1. 设计模式与 UI 接入点

| # | 模式 | 已有构件 | UI 侧接入点 | 负责 |
|---|---|---|---|---|
| 1 | 单例 | `ServiceFactory`、`ConfigManager`、`DbUtil` | UI 不直接 new Service；通过 Controller 构造器/默认单例间接使用 | 成员1 已实现 |
| 2 | 工厂 | `DaoFactory`、`ServiceFactory` | Controller 内部通过工厂取 Service；UI 不直接调用工厂 | 成员1 已实现 |
| 3 | 策略 | `ItemSortStrategy` + `LatestItemSortStrategy`、`PriceAscItemSortStrategy`、`PriceDescItemSortStrategy`、`CreditFirstItemSortStrategy` | 检索页排序下拉框 → `ItemQuery.setSortBy("LATEST/PRICE_ASC/PRICE_DESC/CREDIT_FIRST")` | 成员3 接 UI |
| 4 | 观察者 | `ItemEventBus`、`ItemEventListener`、`CreditChangeListener`、`OperationLogListener`、`StatisticListener` | 发布/成交/评价后订阅刷新检索列表、我的物品、统计页 | 成员3 接 UI |
| 5 | 模板方法 | `AbstractJdbcDao`、`AbstractCsvExporter`、`CsvExporter` | 统计页“导出 CSV”走 `StatisticController.exportCsv`，不自己拼文件 | 成员3 接 UI |
| 6 | 可选：建造者 | `ItemQuery` 链式设置（建议） | 检索条件多时使用 `ItemQueryBuilder` | 迭代二可选 |

## 2. 策略模式：排序下拉框

UI 不写 `if/else` 排序，只把用户选择映射为 `sortBy`：

```java
String sortBy = switch (sortCombo.getSelectedIndex()) {
    case 1 -> "PRICE_ASC";
    case 2 -> "PRICE_DESC";
    case 3 -> "CREDIT_FIRST";
    default -> "LATEST";
};
query.setSortBy(sortBy);
```

`ItemDaoImpl` 已按 `sortBy` 选择 `ItemSortStrategy` 实例；新增排序只需加策略类，不改 UI。

## 3. 观察者模式：跨页面刷新

### 事件源

- 发布物品：`ItemService.publish` 触发 `ItemEvent`。
- 成交/评价/信用变化：`TradeServiceImpl`、`ReviewServiceImpl` 触发事件。
- `OperationLogListener`、`StatisticListener` 已在成员1 侧注册。

### UI 订阅方式

```java
ItemEventBus.getInstance().subscribe(event -> {
    if (event.getType() == ItemEventType.ITEM_PUBLISHED
            || event.getType() == ItemEventType.ITEM_SOLD) {
        SwingUtilities.invokeLater(this::refreshTable);
    }
});
```

- 订阅回调里只做 `SwingUtilities.invokeLater` 刷新，不做查询。
- 页面 dispose 时取消订阅，避免内存泄漏（`ItemEventBus.unsubscribe(listener)`）。
- 不在 UI 里直接 new `ItemEventListener` 实现业务规则；只做“刷新视图”。

## 4. 模板方法：CSV 导出

统计页只负责：

1. 选择时间范围；
2. 选择保存路径（`JFileChooser`）；
3. 调 `StatisticController.exportCsv(path, from, to)`；
4. 提示导出成功/失败。

CSV 的表头、行拼接、字符集、写文件由 `AbstractCsvExporter` / `CsvExporter` 完成；UI 不拼 CSV 字符串。

## 5. 分层复用约束

- UI 只 import：`controller`、`dto`、`entity`、`exception`、`util.Validator`（如需前端校验）。
- UI 禁止 import：`service`、`service.impl`、`dao`、`dao.impl`、`util.DbUtil`。
- Controller 负责异常翻译与参数适配；UI 只负责展示。
- 不允许在 UI 里写 `DriverManager`、`Connection`、`PreparedStatement`、`commit/rollback`。

## 6. 迭代一验收

- 本说明列出 5 个已落地模式的 UI 接入口；
- 检索页排序、统计导出、事件刷新在迭代二/三按本说明接入；
- 成员3 不修改成员1 的 `ItemSortStrategy`、`ItemEventBus`、`AbstractCsvExporter` 实现。
