## 1. PPT 结构（10—12 页）

1. **封面**：低碳校园资源循环流转桌面系统；3 人组；迭代一。
2. **项目背景**：校园闲置教材/数码/文体/生活物资分散，缺少本地桌面管理。
3. **需求范围**：普通学生 + 管理员；发布、检索、收藏、沟通、流转、评价、统计、后台。
4. **架构分层**：Swing UI → Controller → Service → DAO → SQLite；UI 不碰 SQL。
5. **模块划分**：12 包、7 个 Service、11 张表；成员1/2/3 边界。
6. **UML 与数据库**：类图/时序图/ER 图各一张缩略图；11 表 93 列。
7. **设计模式**：单例、工厂、策略、观察者、模板方法；每个给一个类名。
8. **迭代一 UI 骨架**：登录窗 + 主界面截图；说明只交付骨架，不冒充完整功能。
9. **构建与交付**：Maven 坐标、`run-ui.bat`、`start.bat`、JDK/SQLite 版本。
10. **测试与质量**：11 条 JUnit、数据库约束反例、代码走查。
11. **迭代二计划**：登录/检索/发布/流转主链路；成员2 补 Service 测试。
12. **风险与应对**：Swing 工作量、Maven 环境、db 路径、演示账号。
