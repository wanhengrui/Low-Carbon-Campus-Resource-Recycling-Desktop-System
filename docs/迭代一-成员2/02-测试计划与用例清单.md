# 测试计划与用例清单

本轮验收对象为成员2的迭代一业务与测试基线。测试计划覆盖 D1 的 UC-01～UC-08，并为迭代二的用户与物品业务保留优先级。现有测试和后续计划均按 [业务规则核对](01-业务规则与接口核对.md) 的口径判断。

## 运行方式

在仓库根目录执行：

```powershell
cd green-campus
mvn test
mvn "-Dtest=UserServiceTest,BusinessFlowTest" test
```

现有测试位于 [src/test/java](../../green-campus/src/test/java/)。`PasswordUtilTest` 和 `ValidatorTest` 直接测试口令与输入规则。`UserServiceTest` 和 `BusinessFlowTest` 经过 Service、真实 DAO 与 SQLite，属于集成测试，随 `mvn test` 执行。

每条集成用例通过 JUnit `@TempDir` 使用独立 SQLite 文件，由 `TestDatabase` 运行工程建库脚本，数据由用例创建。两个集成测试类用 `@Isolated` 避免测试并行时争用全局 JDBC URL 和监听器。用例结束后恢复 JDBC URL，故障注入监听器在 `finally` 中注销。JUnit 管理临时文件清理。

成交回滚测试在原有日志及信用监听器完成写入之后抛出故障。重新读库核对流转状态及完成时间、物品状态、双方用户信用、信用流水和操作日志。异常错误码与库内原子性分别验收。

## 测试门禁

迭代一交接检查编译通过、现有 JUnit 全部执行、空库演示完成，以及已知差异登记。迭代二先补 T01～T03 和所依赖的规则。组内分工文档提出至少33个 JUnit 用例和 Service 行覆盖率至少60%，用例总数和覆盖率分别核验。实际覆盖以需求追踪表与测试报告为准。
